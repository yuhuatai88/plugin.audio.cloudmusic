# plugin.audio.cloudmusic —— 云音乐 Kodi 插件（网易云音乐 + QQ音乐）

零第三方依赖的 Kodi 音频插件，一个插件内含两个音源：打开插件先选「网易云音乐 / QQ音乐」，各自的登录态、设置与缓存完全独立。只用 Python 标准库 + Kodi 内置模块 + 自带实现（AES 加密、二维码生成与解码），无需安装 xbmcswift2 / requests / pycryptodome / qrcode 等任何第三方模块。

## 功能特性

### 网易云音乐
- 登录方式：扫码 / 手机号+密码 / 短信验证码 / 邮箱 / 粘贴 Cookie
- 登录后：我的歌单、每日推荐，可播放会员歌曲
- 浏览：官方榜单（63 个）、热门歌单、搜索
- 音质：标准 / 极高 / 无损 / Hi-Res 切换，取不到自动降档
- 登录诊断：一键查看各接口真实返回码

### QQ音乐
- 浏览：全部排行榜（巅峰榜/地区榜/特色榜/全球榜）、搜索、歌单、专辑
- 不登录也能听：热歌榜 300 首（128k/192k）
- 登录方式：扫码（666px 大二维码）/ 手机号+短信验证码 / 粘贴 Cookie
- 登录后可尝试：320k / FLAC / APE / VIP 歌曲（取决于账号与版权）
- 高音质诊断：逐档查看实际能否取到播放地址

### 通用
- 登录态本地保存，重开 Kodi 无需重新登录
- 兼容 Kodi 19 (Matrix) / 20 (Nexus) / 21 (Omega)，含 Xbox UWP 版

## 安装方法

1. 下载本仓库代码并打包为 zip（或直接下载 Releases 包）
2. Kodi 中进入「插件」→ 右上角「安装来自 zip 文件」
3. 选择 zip 包安装
4. 安装后在「插件 → 音频插件」中找到「云音乐」

> 网易云如遇风控（错误码 -462），请用「扫码登录」或「粘贴 Cookie」；QQ音乐推荐扫码登录。若装过独立的 plugin.audio.qqmusic，其登录态会自动迁移；装过旧版 plugin.audio.netease 的，网易云登录态也会自动迁移。

## 目录结构

```
plugin.audio.cloudmusic/
├── addon.xml                 # 插件清单（id、版本、许可证）
├── main.py                   # 统一入口：首页选音源，按 src=ne/qq 分流
├── icon.png / fanart.png     # 图标与背景图
├── LICENSE                   # GPL-2.0 许可证
└── resources/
    ├── settings.xml          # 插件设置（网易云与 QQ 分区）
    ├── lib/
    │   ├── ne_app.py         # 网易云音乐 页面与登录逻辑
    │   ├── netease.py        # 网易云音乐 API 封装
    │   ├── aes.py            # AES 加密实现（零依赖）
    │   ├── qq_app.py         # QQ音乐 页面与登录逻辑
    │   ├── qq.py             # QQ音乐 API 封装
    │   ├── qrimg.py          # 官方二维码图片解码放大（零依赖）
    │   ├── qr.py             # 二维码生成 / 纯色图（零依赖，两音源共用）
    │   └── __init__.py
    └── skins/Default/720p/qr.xml   # 扫码登录界面（两音源共用）
```
